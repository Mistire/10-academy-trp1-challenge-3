# Meta Specification: Project Chimera Foundation

## 1. Goal Description
The primary objective of Project Chimera (2026 Edition) is to establish a self-governing, autonomous influencer network. This feature (001) builds the "Golden Environment"—the infrastructure factory required to operate a swarm of persistent, goal-directed AI entities.

## 2. Core Safeguards
- **Immutable Constitution**: No agent action can override the governing principles in `.specify/memory/constitution.md`.
- **Economic Ceiling**: Mandatory daily USDC spend limits enforced by the CFO Judge.
- **Privacy Threshold**: No PII detection/storage without explicit Super-Orchestrator ratification.

## 3. Governance Protocol
- **Spec-Driven Development (SDD)**: All code maps back to executable specs.
- **MCP Traceability**: Mandatory handshakes logged for every tool invocation.

## 4. High-Level Stack
- **Reasoning Agents**: Google Gemini (Pro/Flash).
- **Communication Protocol**: Model Context Protocol (MCP).
- **Environment**: Python 3.11+, `uv` for sandbox management.
- **Persistence**: Redis (Episodic) and Weaviate (Semantic Memory).
